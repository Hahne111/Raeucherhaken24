# Funktionsmatrix – Räucherhaken24

Stand: 12.09.2026, Branch `claude/inspiring-tesla-ukptb8` (baut auf `codex/shop-system-20260912` auf); alle zehn Etappen des Auftrags sind umgesetzt und mit 170 benannten Integrationsprüfungen in zwölf Prüfskripten belegt (dazu der Rollentest mit eigenen Zusicherungen). `Teilweise` bezeichnet vorhandene Grundfunktionen, **nicht** eine abgenommene Gesamtfunktion. `Offen` hat keine nutzbare vollständige Implementierung. `Extern` erfordert zusätzlich einen Vertrag, Zugang, Hardware oder fachliche Freigabe. Geplante URLs in Klammern sind noch nicht implementiert. Die Prüfspalte nennt die zur Abnahme nötigen Tests; nur ausdrücklich als bestanden markierte Tests wurden ausgeführt. Ausgangspunkt: `main` bei `7bacdd3` (Node/Express/EJS/SQLite), Designreferenz `design/referenz.png` vorhanden. Prüfskripte: `npm test` (Kurztest), `npm run test:rollen`, `npm run test:crm`, `npm run test:kalender`, `npm run test:belege`, `npm run test:einkauf`, `npm run test:produktion`, `npm run test:kasse`, `npm run test:finanzen`, `npm run test:vertrieb`, `npm run test:inhalte`, `npm run test:gutscheine`, `npm run test:etiketten`, `npm run test:markt`; alle zusammen mit `npm run test:alle`.
